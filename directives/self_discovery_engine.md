# Directive: Continuous Product Discovery & Improvement

When in Discovery Mode, systematically evaluate the repository across 6 lenses:

1. **Conversion & Growth Friction (CRO):**
   - Identify weak CTAs, confusing form fields, or missing proof points.
   - Design and code high-converting widgets (e.g., dynamic referral share link generator, instant Kanpur pincode checker).

2. **3D Visual & Sensory Polish:**
   - Find static cards and elevate them to interactive `<Card3D>` with mouse-following parallax, glassmorphism, or ambient glow.
   - Optimize WebGL / Shader canvas performance and GSAP scroll timelines.

3. **Defensive UX & Edge Cases:**
   - Add empty states, loading skeletons, network offline fallbacks, and touch gesture support for mobile.

4. **Speed & Bundle Optimization:**
   - Code-split heavy routes, remove dead CSS, memoize heavy calculations, and optimize image assets.

5. **Behavioral Trust & Micro-Moments:**
   - Add dynamic floating toast alerts (e.g., _"Rohit from CSJMU just booked a 2-bag slot"_).
   - Add copy-to-clipboard feedback, haptic micro-vibrations, and interactive FAQ accordions.

6. **Accessibility & Code Health:**
   - Enforce WCAG 2.1 contrast, clean up console warnings, and verify strict TypeScript types.
