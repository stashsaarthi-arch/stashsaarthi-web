# speckit.plan
Breaks down an existing `spec.md` into a structured, chronological `plan.md` using `.specify/templates/plan-template.md`. Every step must follow the `.agents/rules/ponytail.md` 6-step ladder (Zero bloat, native APIs first, direct Supabase, no fake engines).
