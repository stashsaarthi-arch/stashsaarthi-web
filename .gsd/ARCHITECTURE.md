## Data Flow

1. User interacts with UI components in `src/pages` or `src/components`.
2. React Query (`@tanstack/react-query`) or raw Supabase client handles data fetching from Supabase PostgreSQL.
3. Supabase Edge Functions handle complex operations like invoice generation or host photo verification.
4. UI updates reactively based on data changes.
